dlr_wasm_interpreter::execution::instructions

Module dispatch 

Source
Expand description

The Wasm specification defines small-step reduction rules for all instructions so that a list of instructions can be reduced to some result value under some context C.

An interpreter instead executes the instructions one by one with some interpreter state State. This iterative execution logic can be split into two parts: (1) instruction handlers that correspond to small-step reductions and (2) dispatching logic that decides when each instruction handler is called.

This module deals with dispatching, i.e. deciding which instruction handler to execute and when. Multiple dispatch mechanisms are available, each with their advantages and disadvantages. The dispatch mechanism to use can be configured via Config::DISPATCH_MECHANISM.
